Python virtual environment
--------------------------
The project uses a scratch virtual environment with system-site-packages enabled, so it can see the DelftBlue module packages such as torch, numpy, pandas, h5py, and PIL, while adding hdf5plugin.

Create it once:

python -m venv --system-site-packages /scratch/dgogoana/osteophytes_project/venvs/torch_h5env
source /scratch/dgogoana/osteophytes_project/venvs/torch_h5env/bin/activate
python -m pip install --upgrade pip
python -m pip install hdf5plugin

Important H5 note
-----------------
The H5 image datasets use HDF5 filter ID 32026 / blosc2.

Any Python file that reads H5 image arrays must import hdf5plugin before reading arrays with h5py:

  import hdf5plugin

Without this, h5py can inspect metadata but fails when reading image arrays.
